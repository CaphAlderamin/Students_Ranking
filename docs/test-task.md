**Тестовое задание на соискание вакантной должности - ведущего программиста**

Задача: **Автоматическое распределение студентов по условию.**

1.  **Предоставить ER-диаграмму структуры базы данных (**основных таблиц для хранения данных, нормализация хранения данных**).**
2.  **Разработать два алгоритма ранжирования студентов (**код написать в виде классов на РНР, продемонстрировать возможности ООП в реализации кода**).**
3.  **После работы алгоритма должны сформироваться текстовый файл на каждую инженерную школу (**колонки в файле: учебный год, номер семестра, ИД дисциплины, ИД студента**).**

**Вводные данные.**

Задача заключается в распределении всего контингента студентов 1-го курса, одного года приема, одной формы обучения и одного уровня квалификации на модули (модуль - это набор из 3-х дисциплин с изучением в 3,4,5 семестрах).

Модули поделены по следующим параметрам:

1.  модули технические (для технических специальностей)
2.  модули гуманитарные (для нетехнических специальностей)
3.  свободные модули (на них распределяются студенты - не прошедшие конкурсный отбор), количество свободных модулей ограничено (3 модуля, каждый модуль для определенных инженерных школ).

У модуля есть две характеристики - минимум для открытия и максимум для записи. Модуль считается открытым - если на него записалось и распределилось больше минимального числа студентов. Количество заявок ограничено - максимальным числом. Если модуль не открыт (количество заявок по всем приоритетам меньше минимума) - заявки студентов на этот модуль не участвую и студентам предлагается следующий модуль по списку его приоритетов. Если модуль открыт, но студент по рейтингу ниже максимального числа - то ему предлагается следующих модуль. Студенты, которые не прошли не на один модуль - распределяются на свободные модули. Студенты которые не подали заявки - сразу распределяются на свободные модули (за исключением целевой квоты). Студент может быть распределен только на один модуль. Все студенты должны быть распределены.

**Процедура сбора данных.**

1.  Студенты подают заявки в установленные даты (1 учебная неделя).
2.  Студенты выбирает до 3-х модулей с указанием желаемого приоритета распределения.
3.  Студенты могут выбирать только технические или нетехнические модули - согласно студенческой группе в которой они учатся.

**Критерии студентов.**

1.  студенты, обучающиеся по целевой квоте - идут вне конкурса.
2.  студенты, обучающиеся на платной основе имеет более высокий рейтинг, чем студенты на бюджетном финансировании.
3.  для рейтинга используются сумма результатов ВИ при поступлении в ВУЗ (не учитывая русский язык и индивидуальные достижения).
4.  средний балл аттестации за 1 и 2 семестра по итогам сессии.
5.  средний балл по базовым предметам.
6.  результаты входного тестирования.
7.  студенты инвалиды имеют дополнительный балл к рейтингу.

Ранжирование студентов (алгоритм распределения должен предусмотреть 2 варианта распределения студентов).

1.  первый алгоритм распределяет студентов по дате подачи заявки.
2.  второй алгоритм распределяет студентов по критериям.
