# 🎓 Students Ranking

Автоматическое распределение студентов 1-го курса ТПУ на модули дополнительной специализации по двум алгоритмам ранжирования (по дате заявки и по критериям) с формированием отчётных файлов по инженерным школам.

- **Статус:** в разработке
- **База знаний (SSOT):** локальный Obsidian-ваулт `data-vault/` (не коммитится — личный артефакт команды)
- **Стек:** PHP 8.3, MySQL 8.4, Composer (см. `composer.json`)
